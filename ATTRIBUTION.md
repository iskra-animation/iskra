# Attribution

Everything in Iskra that comes from somewhere else, with its source and licence.

Clean-room rule: Iskra contains no code, assets, icons or branding from other animation apps.

## Vendored source code

These crates are copied from the ArtCraft apps into `crates/third_party/` by
[`scripts/vendor.sh`](scripts/vendor.sh), which holds the pinned commits. All are
MIT OR Apache-2.0; the upstream `LICENSE-MIT`, `LICENSE-APACHE` and `NOTICE` are kept beside them.

Changes from upstream, the same for every crate:

- The sources are unchanged, but for the patches in [`scripts/patches/`](scripts/patches/), which
  the script applies and each of which says what it changes and why. Now one:
  `photocraft/paint/src/render.rs`, `StrokeRenderer::coverage_in` reads the coverage tile by tile.
- `Cargo.toml` is rewritten: the package is renamed to `iskra-<repo>-<crate>` and stands alone in
  this workspace. The library keeps its upstream name (`photocraft_geom`, …), which is why the
  sources need no edits and upstream fixes can be taken as a plain diff.

### PhotoCraft

Source: <https://github.com/storytold/photocraft> at commit `ff4738810134d7f7e68b49f2e4f231b686282ff3` (2026-10-22).
Copyright (c) 2026 ArtCraft Team and the PhotoCraft contributors.

| Path | Upstream crate | What it is |
|---|---|---|
| `crates/third_party/photocraft/geom` | `photocraft-geom` | 2D geometry: points, rects, transforms, warps |
| `crates/third_party/photocraft/cms` | `photocraft-cms` | ICC colour management (a dependency of `photocraft-color`) |
| `crates/third_party/photocraft/color` | `photocraft-color` | Pixel colour types, conversion, blend modes |
| `crates/third_party/photocraft/raster` | `photocraft-raster` | Copy-on-write tiled pixel surfaces |
| `crates/third_party/photocraft/paint` | `photocraft-paint` | Raster brush engine |
| `crates/third_party/photocraft/tablet` | `photocraft-tablet` | Pen tablet input on macOS and Linux X11, and the barrel button on Windows |
| `crates/third_party/photocraft/psd` | `photocraft-psd` | Reader and writer for Photoshop files, written clean-room from public descriptions of the formats. Used for brush files (`.abr`) now, and for character import later |

`crates/third_party/photocraft/cms/profiles/photocraft-coated-cmyk.icc` is a synthetic ICC profile
generated by `photocraft-cms` itself: original work of the PhotoCraft contributors, CC0-1.0.

Source: <https://github.com/storytold/vectorcraft> at commit `4a7cba0dd32e4ac249e4dc50af486b89531481aa` (2026-10-23).
Copyright (c) 2026 ArtCraft Team and the VectorCraft contributors.

|---|---|---|
| `crates/third_party/vectorcraft/geom` | `vectorcraft-geom` | Vector geometry over `kurbo`: paths, shapes, hit testing, snapping |

copied but not built: they need `vectorcraft-testkit`, which brings VectorCraft's whole document
model and renderer. The other tests of the three crates are run.
